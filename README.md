# NeuroTranslate

Учебный Android-проект офлайн-переводчика. Цель — переводить текст между русским и английским локально после установки языковых пакетов.

> Сейчас готовы базовые Compose-экраны и переходы между ними. Реальный перевод, установка моделей и загрузчик ещё не реализованы.

## Текущий план

- Приложение на Kotlin, один модуль `app`, минимальная версия Android — API 24.
- Целевые языковые направления MVP: RU → EN и EN → RU.
- Базовые экраны перевода, каталога моделей и настроек; состояние экранов хранится во ViewModel.
- В перспективе: Marian ONNX, каталог пакетов, установка и удаление моделей, возобновляемые загрузки и экран настроек.
- Файлы весов моделей не хранятся в Git. Ревизии, размеры и контрольные суммы будут зафиксированы до интеграции моделей.

## Требования для сборки

- Android Studio с JDK 17.
- Android SDK Platform 37 и Android SDK Build-Tools 36.0.0.
- Gradle Wrapper 9.6.0 (скачивается wrapper при первом запуске, если его ещё нет в локальном кэше).

Версии проекта: Android Gradle Plugin 9.4.1, `compileSdk = 37`, `targetSdk = 37`, `minSdk = 24`. Сборка AGP 9.4 требует Gradle 9.6.0 и JDK 17.

### Открыть в Android Studio

1. Открой папку проекта.
2. Установи Android SDK Platform 37 и Build-Tools 36.0.0 через SDK Manager, если они ещё не установлены.
3. Выбери JDK 17 для Gradle и выполни Gradle Sync.

### Собрать APK из командной строки

Windows PowerShell:

```powershell
./gradlew.bat assembleDebug
```

Linux/macOS:

```bash
./gradlew assembleDebug
```

Локальный `local.properties`, каталоги сборки, кэши и скачанные веса не должны попадать в Git.

## Статус
