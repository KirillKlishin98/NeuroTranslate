# День 9 — постоянные настройки и ключевые тесты

- Тема и максимальная длина результата сохраняются в Preferences DataStore. Неизвестное значение темы безопасно возвращается к системной, длина результата нормализуется к шагу 16 в диапазоне 64–400.
- Добавлены unit-тесты для границ HTTP Range и валидаторов ETag/Last-Modified, размера/SHA-256 файла, ограничений длины результата, закрытия активной модели до удаления файлов, очистки после ошибки активации и сериализации удаления с переводом.
- Добавлен Android instrumentation test для записи и чтения Preferences DataStore; он компилируется, но требует устройства/эмулятора для выполнения.
- DataStore закреплён на версии 1.3.0 согласно текущей официальной таблице релизов AndroidX.
- `testDebugUnitTest` завершился успешно; `compileDebugAndroidTestKotlin` завершился успешно. Для SDK пришлось остановить старый Gradle daemon и запустить одноразовый daemon с доступом к SDK.
- Подключённых эмуляторов/устройств нет (`adb devices -l` вернул пустой список), поэтому UI и instrumented проверки не выполнялись. Реальный сетевой cancel/resume/SHA сценарий, ONNX-прогон и 10 циклов жизни сессии остаются непроверенными.
