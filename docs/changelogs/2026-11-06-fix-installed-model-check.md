# Исправление проверки установленной модели

- Кнопка перевода больше не показывает запрос на установку без проверки локального репозитория.
- RU → EN проверяет установленный пакет `ru-en`, а EN → RU — `en-ru`; проверка сверяется с манифестом и файлами, которые использует каталог моделей.
- Для установленного пакета UI сообщает, что модель найдена, но перевод пока недоступен из-за неподключённого Android-токенизатора. Ошибку чтения хранилища показывает отдельным сообщением.
- Проверка сборки: `compileDebugKotlin`.
